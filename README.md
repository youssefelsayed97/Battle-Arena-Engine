🥊 Battle Arena Engine

A Python-based object-oriented battle simulation system where players compete in structured battles and tournaments until a final champion is decided.

📌 Overview

This project simulates a combat system between players using attack, defense, and randomized mechanics. Players fight in 1v1 battles, and winners advance through a tournament-style elimination system.

The project is built using Object-Oriented Programming (OOP) principles and demonstrates modular software design.

⚙️ Features
👤 Player system with attributes (health, attack, defense)
⚔️ Battle engine with randomized combat logic
🏆 Tournament system with elimination rounds
🎲 Win / Lose / Draw system
⏱️ Configurable delay for battle simulation
🧠 Object-Oriented architecture (classes & modules)
